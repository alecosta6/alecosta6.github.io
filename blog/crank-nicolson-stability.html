Why the Crank-Nicolson Scheme is Unconditionally Stable: A Von Neumann View

Alessio Costa March 2026 5 min read Numerical Analysis

When solving time-dependent parabolic Partial Differential Equations (PDEs) such as the 1D Heat Equation:

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}, \quad x \in (0, L), \; t > 0$$

explicit numerical methods (such as Forward Time Centered Space / FTCS) suffer from a severe time-step constraint known as the CFL stability condition: $r = \frac{\alpha \Delta t}{\Delta x^2} \le \frac{1}{2}$. If $\Delta x$ is halved, the permissible time-step $\Delta t$ must be reduced by a factor of four.

The Crank-Nicolson method, introduced by John Crank and Phyllis Nicolson in 1947, resolves this computational bottleneck by averaging the explicit and implicit spatial stencils at time levels $n$ and $n+1$.

1. Discretization Stencil

Let $u_j^n \approx u(x_j, t_n)$ where $x_j = j \Delta x$ and $t_n = n \Delta t$. Replacing the time derivative with a forward difference at the half-step $t_{n+1/2}$ and the second spatial derivative with the arithmetic mean gives:

$$\frac{u_j^{n+1} - u_j^n}{\Delta t} = \frac{\alpha}{2} \left( \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{\Delta x^2} + \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{\Delta x^2} \right)$$

Defining the dimensionless mesh ratio parameter $r = \frac{\alpha \Delta t}{\Delta x^2}$, we rearrange into the classical tridiagonal linear system:

$$-\frac{r}{2} u_{j-1}^{n+1} + (1 + r) u_j^{n+1} - \frac{r}{2} u_{j+1}^{n+1} = \frac{r}{2} u_{j-1}^n + (1 - r) u_j^n + \frac{r}{2} u_{j+1}^n$$

2. Von Neumann Stability Analysis

To examine numerical stability, we express the spatial distribution of the error as a Fourier series and analyze the evolution of an arbitrary Fourier mode:

$$u_j^n = G^n e^{i k x_j} = G^n e^{i j \xi}$$

where $\xi = k \Delta x \in [-\pi, \pi]$ represents the phase angle and $G \in \mathbb{C}$ is the amplification factor. Substituting into the difference equation:

$$G \left[ -\frac{r}{2} e^{-i\xi} + (1 + r) - \frac{r}{2} e^{i\xi} \right] = \frac{r}{2} e^{-i\xi} + (1 - r) + \frac{r}{2} e^{i\xi}$$

Using Euler's identity $e^{i\xi} + e^{-i\xi} = 2 \cos(\xi)$ and the half-angle trigonometric relation $1 - \cos(\xi) = 2 \sin^2(\xi/2)$:

$$G \left[ 1 + r(1 - \cos\xi) \right] = 1 - r(1 - \cos\xi)$$
$$G(\xi) = \frac{1 - 2r \sin^2\left(\frac{\xi}{2}\right)}{1 + 2r \sin^2\left(\frac{\xi}{2}\right)}$$
Theorem (Unconditional A-Stability)
For any physical diffusion parameter $\alpha > 0$ and any positive spatial and temporal step sizes $\Delta x, \Delta t > 0$, the parameter $r > 0$. Since $\sin^2(\xi/2) \ge 0$, the denominator is strictly greater than or equal to the numerator in absolute value: $$\left| G(\xi) \right| = \left| \frac{1 - 2r \sin^2(\xi/2)}{1 + 2r \sin^2(\xi/2)} \right| \le 1 \quad \forall \xi \in [-\pi, \pi]$$ Hence, the Crank-Nicolson method is unconditionally stable in the $L^2$ norm.

3. Order of Accuracy & Practical Notes

By Taylor series expansion around $(x_j, t_{n+1/2})$, it is straightforward to show that the truncation error is:

$$\tau_j^n = \mathcal{O}(\Delta t^2) + \mathcal{O}(\Delta x^2)$$

This second-order temporal and spatial accuracy makes it significantly superior to implicit Backward Euler (which is only $\mathcal{O}(\Delta t)$ in time), while avoiding any step-size restriction.

4. Python Implementation

import numpy as np
from scipy.linalg import solve_banded

def crank_nicolson_1d(u0, alpha, dt, dx, nt):
    """
    Solves du/dt = alpha * d2u/dx2 using Crank-Nicolson.
    """
    nx = len(u0)
    r = alpha * dt / (dx**2)
    
    # Construct tridiagonal LHS and RHS
    main_diag = (1 + r) * np.ones(nx - 2)
    off_diag = (-r / 2) * np.ones(nx - 3)
    
    # Banded matrix for scipy
    ab = np.zeros((3, nx - 2))
    ab[0, 1:] = off_diag
    ab[1, :] = main_diag
    ab[2, :-1] = off_diag
    
    u = u0.copy()
    for _ in range(nt):
        rhs = (r/2)*u[:-2] + (1-r)*u[1:-1] + (r/2)*u[2:]
        u[1:-1] = solve_banded((1, 1), ab, rhs)
    return u
